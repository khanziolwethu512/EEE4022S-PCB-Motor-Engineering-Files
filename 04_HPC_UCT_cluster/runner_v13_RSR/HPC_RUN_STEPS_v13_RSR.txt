R-S-R DESIGN STUDY (v13) - UCT HPC run steps                                                       23 Oct 2026
======================================================================================================
R-S-R = one Rev0 stator (5 boards) between two Rev0 rotors. The lower rotor's magnets face the stator from below
with the SAME magnetisation vector as the upper ones, so the field passes straight through the stator. Original
geometry: 1.0 mm gaps both sides, 2 mm steel plates, 86/19 mm. Simulation-only design study (not built).

hpc_motor.py in this folder: file sha da450e6ccb1c, code folder code_33a7dc7bdc. It contains every earlier profile
too, so it replaces the v12 runner.

ALWAYS SUBMIT FROM YOUR HOME FOLDER WITH ~/hpc_motor.py (submitting from /scratch picks up an old copy).

WHAT RUNS
  Batch A (now, together):
    FIELDMAP_REV0_HW    method check on the KNOWN Rev0: 12 angles over half a period + the new post-processing
                        (waveform, eddy from the static field, plate |B|). Must reproduce the archived rotating run:
                        K1 19.47, E1 1.442 V rms/1000 rpm, THD 5.5 %, ripple 1.26 %, eddy 20.35 mW.   16 cores, ~2-4 h
                        (ignore its "VALIDATION GATE ... 6.0917 FAIL" line - that old gate value predates the 20 mm runs)
    FIELDMAP_RSR_P20    R-S-R machine: K, back-EMF waveform/harmonics, ripple, eddy loss, both plates' |B|   16 cores, ~2-4 h
    DIAG_RSR_B1/B2/B3   detailed boards 1-3 in the R-S-R environment, +/-I (the reference K, like Rev0)      8 cores each, ~3-4 h
  Batch B (after batch A has finished AND you have cleaned the disk, see C):
    DIAG_RSR_B4/B5      detailed boards 4-5                                                                  8 cores each, ~3-4 h
    EQ_RSR_ISWEEP       current sweep 0/1/3 A + armature-only inductance (needs FIELDMAP_RSR_P20 finished)   24 cores, ~5-7 h

ACCEPTANCE (fixed before the runs)
----------------------------------
FIELDMAP_REV0_HW vs the archived FMROT_REV0 (job 1500352): K1 within 0.5 %, E1/1000 rpm within 0.5 %, H3 within 0.3
  points, ripple within 0.2 points, eddy within 5 %. Pass -> the static post-processing is valid for R-S-R.
DIAG_RSR_B*: copper (+I - -I)/2 vs rotor virtual work within 3 %; board psi within 1 deg of each other.
R-S-R machine K: the detailed-board sum is the reference; it should land within ~1 % of the independent analytical
  sheet-current prediction, and the field map should read ~2-6 % above it (the known centre-line routing effect).
